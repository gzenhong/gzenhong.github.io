Chest

Glutes

Calves

小腿 — 膝角度決定練哪一塊

膝一彎，腓腸肌鬆弛失去發力，比目魚肌被迫接管。這就是為什麼只做站姿提踵，小腿永遠差一塊。

Push / Pull / Legs

PPL 課表 — A/B 雙版本輪替

器材前提：可調式啞鈴 + 可調式 bench + 門框單槓。每次 50–65 分鐘，所有動作留 1–3 RIR（保留次數），最後一組可到力竭。

Why Push → Legs → Pull8 天版把腿插在推與拉之間，有兩個理由：① 握力與二頭在 Pull 日是瓶頸，前一天練腿不會佔用它們；② Legs 日的 RDL 已大量使用握力與豎脊肌，隔天再拉會疊加疲勞，所以順序不能顛倒成 Pull → Legs。

每 4 天插一天全休，相當於每個部位 8 天練兩次——比 6 天版少一點量，但每次都能全力輸出。工作日不固定的人也更好排，因為它不綁星期。

Deload每 6–8 週安排一週減量：重量減 40%、組數砍半、動作不變。不是休息，是讓結締組織與神經系統追上肌肉。
